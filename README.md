# Interactive Reinforcement Learning Toolkit

## Project Overview
This project implements multiple reinforcement learning algorithms in a unified environment to analyze and compare different learning strategies. It includes both model-based and model-free methods for learning optimal policies through interaction with an environment.

## Algorithms
- Value Iteration  
- Policy Iteration  
- Monte Carlo Control  
- Temporal Difference Learning  
- Q-Learning  
- SARSA  

## Core Idea
An agent learns optimal behavior by interacting with an environment and improving its policy based on reward feedback using different reinforcement learning techniques.

## Workflow
1. Initialize environment and states  
2. Agent interacts with environment  
3. Receive reward and next state  
4. Update values or Q-tables  
5. Improve policy  
6. Repeat until convergence  

## Outputs
- Learned policy per algorithm  
- State-value function (V)  
- Action-value function (Q)  
- Performance comparison across methods  

## Tech Stack
- Reinforcement Learning  
- Custom Environment API  

## Goal
To provide a clear and comparative implementation of reinforcement learning algorithms for educational and experimental purposes.
